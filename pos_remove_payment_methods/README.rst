=======================================================
POS: clear the payment lines on screen entry
=======================================================

* Automatically removes all selected payment lines when navigating back from the Payment screen to the Product screen

* Helps to prevent accidental duplication of payment entries when switching screens

* Ensures a clean payment state when re-entering the Payment screen

Usage
-----

* Open Main menu -> Point of Sale -> Start a session

* Add products to the cart and proceed to the Payment screen

* Select one or more payment methods

* Click the back button to return to the Product screen

* Navigate back to the Payment screen

* RESULT: all previously selected payment lines will be cleared

* When going back to the Payment screen, no payment lines will remain from the previous attempt
